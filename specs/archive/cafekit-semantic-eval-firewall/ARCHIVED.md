# Archived: CafeKit Semantic Eval Firewall

Archived on 2026-08-19 when the Specs authoring workflow moved from the
semantic-kernel v2.1 bundle to the process-first v3 layout. This directory is a
historical record and is not an active workflow candidate.

The anchors to `skills/specs/rules/design-principles.md` in the preserved
`spec.json` describe the retired v2.1 implementation. They remain here for
historical traceability even though that rule is no longer shipped by v3.

Do not run the active-spec validator against this archived path: that validator
derives its project root from an active `specs/<feature>/` layout. The live
change-firewall reads only the archived bootstrap artifacts it explicitly owns.
