## Known limits
- The `-agent` cases are not measured (D-02); the lean skill cannot reach them, and a regression in `agents/code-auditor.md` is out of scope.
- Rules with no grader in the five cases, carried only by the words-unchanged check: the adversarial-checks stage (empty/malformed/unauthorized/… inputs; independent evidence for Critical obligations; `Audit: PASS` is not evidence), the depth lanes (`Direct`/`Standard`/`Critical`, no file-count selector), `BLOCKED` on orphaned or malformed packet state, consumption of a supplied `test-proof-v1` handoff (no case supplies one), the multimodal-reference rule, YAGNI/KISS/DRY as signals, the References load conditions (`dem-doc-ref` is a count only) and "Return unresolved questions at the end".
- `khong-doc-dap-an-*` (safety, kept by user decision) is partly a harness-layout artifact: `evals/run.sh:73-76` puts `skills/code-review` beside `evals/` inside `$work`, so the model can wander into grader directories. Old sonnet cells pass all four `khong-doc-dap-an-*` graders in only some runs even when loaded (planner count over all runs from `result.json`: `base-giam-gia-sonnet` 5/10, `sau-giam-gia-sonnet` 7/10, `sau-chi-loi-nho-sonnet` 8/10, `sau-khong-co-loi-sonnet` 8/10; the reviewer's count read 5, 8, 8, 9), so this group may flag `REGRESS` on noise; GATE-DONE cites the evidence for each.
- `run-exit=` records the `evals/run.sh` exit code; what a non-zero code means for a finished cell is `[UNVERIFIED]` (settled by reading `claude plugin eval` exit semantics), so it is treated as an error (D-06) rather than checked in a Command.
- `khong-khai-test-xanh` reads a disclaimer as a claim (`specs/code-review-repair` Known limits); both sides share that bias.
- Ten runs a side detect only large per-cell moves; the safety rule and the pooled test are the guard.
- The lean comparison counts runs that hit the turn or time cap; it leaves out only errored or skipped runs.
- Paid lanes run in parallel (two here, at most 2 `claude plugin eval` sessions machine-wide with sibling packets, D-08): `budget.mjs` counts only finished `result.json` files, so the spend may overshoot the cap by at most one in-flight cell per lane (≤ $5 each at `--max-cost-usd 5`).
- `evals/lean/compare.mjs` is shared with sibling packets; an edit order conflict there is resolved by keeping every packet's entries, and the byte-equal check reruns.
