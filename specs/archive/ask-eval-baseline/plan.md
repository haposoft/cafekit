# Ask eval baseline — measure cf:ask on five repository questions
Specs-Contract: process-first-ready-v1

## Scope decision (GATE-SCOPE — 2026-10-04)
- Existing:
  - `cf:ask` is one `SKILL.md` plus `templates/question.md` (`packages/spec/src/claude/skills/ask/`). Its contract: answer only, never edit (`SKILL.md:25-28`); repo evidence first, in a stated order (`SKILL.md:77-83`); ask back with one question when the target is unclear (`SKILL.md:97-104`); an Answer / Evidence / Confidence / Gaps / Next output (`SKILL.md:108-126`); "no evidence found in the current source" when nothing answers (`SKILL.md:137`); `--repo` answers from local source only (`SKILL.md:55`).
  - No measurement of `cf:ask` exists. `evals/run.sh <skill> --plugin-name cf` builds the eval plugin from `packages/spec/src/claude/skills/<skill>` (`evals/run.sh:75-96`) and writes `evals/results/<skill>/` (`evals/run.sh:123-131`); it copies the whole `evals/<skill>/` beside the plugin, while a scaffold copies only the fixture into the workspace.
  - `evals/test/` holds proven tools for one suite: `save-runs.mjs` (saved runs, `--check-saved`, `--kept`), `compare.mjs` (Fisher, joint members, watch lists), `budget.mjs` (spent, check, ceiling, reserve, fits), `check-fixtures.sh`. The eval host offers no `AskUserQuestion`, so an ask-back appears as text.
- Minimum change: `evals/ask/` with a small fixture project, five cases and their graders, a generator kept in the repo, the three tools adapted from `evals/test/`, a checker; ten pilots; ten cells × 10 runs; a report without a conclusion.
- Expansion signals: none (one new suite directory; no product code).
- User decision: KEEP — five repo-only cases; in `cam-sua` the right behaviour is to explain, not edit, and point to `cf:fix`; cap $50.

## Out of scope
- `--web`, `--both` and external sources; `--brief`/`--deep`; any change to `cf:ask`; `templates/question.md`; agents; pushing unless asked.

## Known limits
- The graders read words; a right answer worded unusually can read as wrong, and the reverse; failed joint runs are hand-read.
- `hoi-lai`'s ask-back is text, because the eval host has no `AskUserQuestion`. The skill allows a cautious answer (`SKILL.md:95`) yet shows this very question as an ask-back (`SKILL.md:166-169`); the grader follows the example (user decision).
- `chi-cf-fix` measures an expectation, not the contract: `SKILL.md` never names `cf:fix` (it routes fixes away at `SKILL.md:43`) and only `ask` is loaded, so its baseline is expected to be low; a later repair packet may change that.
- `khong-bia`'s database names have no word boundary, so a non-negated sentence holding "redistribute" or "Mongoose" reads as an invented database; every run is hand-read.
- The widened `khong-tim-thay` and the per-sentence `khong-bia` can both pass an invented answer such as "Dịch vụ lưu vào PostgreSQL; không thấy file cấu hình riêng."; every run is hand-read.
- `khong-bia` reads negation lexically per sentence: a sentence that negates anything passes, so "không tìm thấy, nhưng có lẽ dùng PostgreSQL" passes and is hand-read; a suggestion such as "có thể thêm SQLite" fails and is hand-read too.
- Sandbox `git` fails with an `xcrun` cache error; the graders read the harness's file state.
- WebSearch/WebFetch are allowed so misuse is visible; cells run one at a time because parallel cells once lost WebFetch at start (`specs/research-eval-baseline`).
