## The trace reader and helpers
- `read-traces.mjs <result dir>...` prints per run: `init=` (the skill registered on the skill path; `brainstormer` registered on the agent path; every tool of the case's `allowed_tools` among the init tools, `AskUserQuestion` excepted and the Agent tool accepted under its init name `Task` — missing any is an incomplete init) and `askuser-offered=yes|no`; the parent's and subagents' tool counts; `askuser=<n>` with each call's question count and its result truncated to 80 characters; `chat-questions=` (lines of the final answer ending with `?`); `skill-calls=`; on the skill path `skill-loaded=history|call|none` (`history` when the case's `history_file` carries the skill-load record, `call` when a `co-goi-skill`-matching call ran, else `none`, listed apart and kept in the counts), and `skill-loaded=n/a` on the agent path; `agent-calls=` (each `subagent_type` and whether its prompt names a route); on the agent path `report-src=` (`sync`, `notification`, `launch-only`, `error` or `none`, classified as `evals/research/read-traces.mjs:65-91` does) and `report=` (each case-4 regex on the report text); `mutations=`; `chars=` of the final answer (the texts of the last `assistant` event carrying text); `agree=yes|no` for every stored `last_message` regex and `tool_used` verdict; and for every failing non-counter grader a `decisive <grader>: <text>` line, as `evals/research/read-traces.mjs:227-240` prints them. Per directory a line with `runs=`, `errored=`, `askuser-errored=` (errored runs whose trace holds an `AskUserQuestion` call, over the directory and its `-lan1` when one exists, which is read for this count only), `counts=` (every non-counter grader's passes over clean runs, the primary set marked), `cost-with-judge=`, `cost-without-judge=` and the `report-src` totals. It exits 1 on a clean run with an incomplete `init`, a disagreement, a clean run without a trace, or, with `--require-brainstormer`, agent-path directories given and no `sync` or `notification` report among them (as `evals/research/read-traces.mjs:257`). `--probe <dir>` prints `init=` and `history-skill=seen|not-seen` (`seen` needs `trich-hard-gate` passed and no tool call in the trace) and exits 1 on an incomplete init or `not-seen`. `--kept <dir>` prints the basename of every run's kept directory (`dirname(dirname(tracePath))` from its `result.json`), one per line, and exits 1 when there is none or one is not a direct child of `/private/tmp`. `--integrity [--runs <n>]` (default ten) prints per directory `partial=… runs=… errored=… retried=… named=… instrument=current|MISMATCH claude=…` (errored: an `error`, `skippedPaidGraders` or fewer graders than its case; named: the directory ends in `-<case>-<model>`; instrument: every stored grader equals its file as `evals/compare-research.mjs` compares them) and `claude-versions=<n>`, and exits 1 on a partial directory without an error (its ceiling), a short or errored directory without its `-lan1`, a `MISMATCH`, `named=false` or more than one version.
- `ceiling.mjs <sonnet|opus> <skill|agent> [results dir]` prints `max(4, ⌈k × the highest costUsd⌉)` over that model's pilots of that path, each read under its own name (the re-run when a `-lan1` exists) and its `-lan1` too, with `k` 12 on the skill path and 15 on the agent path; `budget.mjs <spent | check <next> | worst-case> [--root]` sums `costUsd` over every `result.json` under `<root>/brainstorm/` against $100 (reading its own spent figure whatever any other helper exits), exits 1 above it, and `worst-case` prints spent plus the eight baseline cells' ceilings; `save-answers.mjs --answers <dir> --reports <dir> --models <dir> <result dir>...` writes every run's whole answer, `brainstormer` reports and models under `### run <n>` headers (adapted from `evals/save-research-answers.mjs`). Each has a `--self-test` on synthetic data.
