## Known limits
- The eval runs without hooks or the completion gate. Each loaded skill's whole directory and the agent file reach the run; the answer-read graders allow reads under the plugin's `skills/` and `agents/` and forbid `evals/` and a listing of the plugin root.
- Web results vary by date and region; a search for a fictional name may still return unrelated pages, and the name check above could not use a general web search. `noi-trang-thai-web-llm` judges whether the answer states its web status, not whether the statement is true; `read-traces.mjs` shows whether a web call happened and succeeded.
- The host is kept as shipped (D-12): an async researcher launch tells the parent to "briefly tell the user what you launched … and end your response" (binary text), so in a `-p` run the report may arrive after the parent's final text or never; the pilots showed every async report arriving as the `summary` of a `system`/`task_notification` event for the launch (never as a user-event `<task-notification>`), and every sync report as a `[Subagent hand-back]` tool result; `read-traces.mjs` reads both forms, unframing the hand-back, while its self-test covers only the user-event form.
- Whether a fixture's `CLAUDE.md` is loaded into an eval run's context is `[UNVERIFIED]`; case 3 counts it only as a file in the repository.
- Lexical limits (D-01's break signal applies): `chon-drizzle` and `chon-pg-boss` still pass "Khuyến nghị: không dùng Drizzle" (a negation after the verb) and "because Drizzle…" (the verb `use` inside a word); a concessive clause (`Mặc dù`, `Dù`, `Although`, `Even though`, `Despite`) is rejected only when no comma separates it from the verb, and a later reversal only when `nhưng`/`tuy nhiên`/`but`/`however` is followed within 40 characters by `nên`/`đề xuất`/`khuyến nghị`/`recommend`/`should` and the other option; other concessive words (`Tuy`) and reversals phrased otherwise still pass; `limits-cu` counts "SDK 3.x" beside `limits.md` as marking it old; `du-ba-lech` reads the three vendor values, not that they are called mismatches; `co-nhan-claim` needs a delimiter before the label and excludes an `Unresolved:` line only when it reads none, không, N/A, a dash or nothing; depth graders read `Độ sâu`/`độ sâu`, a `Depth` not preceded by a letter or hyphen, and `mức`/`mức độ`/`mức nghiên cứu` not preceded by `hạn ` (added after the first pilot), case-sensitive in the depth word, on NFC text, and they also pass a hypothetical mention such as "cần chạy mức Standard"; `benchmark-khac-moi-truong` reads a mention of the 8-vCPU machine.
