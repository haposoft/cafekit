## Scope decision (GATE-SCOPE — 2026-10-06)
- Existing: five legacy hooks ship for Claude (`src/claude/hooks/`) and Codex (`src/codex/hooks/`): `completion-authority.cjs`, `completion-authority-check.cjs`, `completion-authority-state.cjs`, `semantic-review-authority.cjs`, `task-scaffold-guard.cjs`. Claude registers three of them (`src/claude/settings/settings.json:59` UserPromptSubmit, `:83-90` a PreToolUse `Write` group holding only the scaffold guard, `:121` Stop, `:135` SubagentStop), Codex the same three (`src/codex/hooks.json:53-54,85-86,113-114,130-131`), omp dispatches two (`src/omp/extensions/cafekit-bridge.mjs:44,45,47`; the bridge blocks a gating event whose listed hook file is missing, `:180-188`). `src/claude/migration-manifest.json:140,144-147` ships all five to Claude and omp. Upgrade pruning: Claude deletes `obsolete.runtimeFiles` unconditionally (`bin/phases/claude-runtime.js:168-190`) and drops settings commands containing an `obsolete.settingsHookCommandSubstrings` entry (`bin/phases/claude-settings.js:20-46`); Codex applies the same substring list to `.codex/hooks.json` (`bin/phases/codex-hooks.js:140-160`) but has no stale-file prune (`bin/phases/codex-runtime.js:59-66` only copies `src/codex/hooks` with `copyManagedTree`); omp prunes `obsolete.runtimeFiles` under `hooks/` with `tracker.keyFor` (`bin/phases/omp-runtime.js:136-150`). Strict validation loads `../hooks/semantic-review-authority.cjs` (`src/claude/scripts/validate-spec-output.cjs:2474-2490`, `:2904-2913`). Both session hooks still clear the authority state inside a `try` (`src/claude/hooks/session.cjs:205`, `src/codex/hooks/session.cjs:91`).
- Minimum change: delete the ten hook files and their two tests; drop every registration, bridge entry and `runtime.files` entry; prune installed copies and registrations on upgrade on all three runtimes (adding a Codex file prune); Strict validation reports "no longer supported"; agent and skill text stops pointing at the removed mechanisms; session hooks stop clearing the authority state; `spec.scaffold_guard` becomes deprecated; the tests that load or run the removed hooks are updated first, so no task leaves its own command red.
- Expansion signals: about 35 files (above eight; 12 deletions, about 20 test edits); one subsystem; no new service.
- User decision (2026-10-06): remove entirely (not conditional) on Claude, Codex and omp; upgrades delete installed copies and registrations on all three; Strict reports a clear "no longer supported"; drop the session-clear; keep `spec.completion_gate`, deprecate `spec.scaffold_guard`; reword `code-auditor.md`, `develop/SKILL.md`, `quality-gate.md`; changelog entries in 3b, other docs in 3c.
