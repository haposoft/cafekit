## Known limits
- The eval runs without hooks or the completion gate. The whole `code-review` skill directory reaches a run, but the sandbox denied `find` and `Glob` into a plugin's `references/` (`specs/develop-repairs/task-08-name-the-provenance-command.md:10`), so `references/verification-gate.md` may never be read; `dem-doc-ref` and `dem-doc-verification-gate` show reads.
- A subagent's own tool calls count in `tool_used` graders only if the trace carries its events; `verify-runs.mjs` prints `sub-events=` per run. The run log, the reflog and the final-tree comparison see the effects either way.
- On the agent path `last_message` is the main agent's final text, which may summarize or reformat the auditor's report; the auditor's report is graded only by `verify-runs.mjs`, from traces that vanish with `/private/tmp`, so each Command reads them before any deletion. The report text may carry a trailing agent-id block.
