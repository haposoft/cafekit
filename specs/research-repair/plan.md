## Known limits
- The agent-path after-runs change the researcher's text and its model together (user decision), so a difference cannot be split between them; the saved `models` lines show which model each researcher ran.
- The parent's relay is host behavior; the files can only ask it to keep the labels, and the host frames a sync report as model output without user authority.
- A label gain may be partly vocabulary: baseline answers already state status in Vietnamese ("chưa kiểm chứng", "suy luận"), which `co-nhan-claim` does not read; the comparison prints those phrases' counts. Labels and anchors lengthen answers; `do-dai-gon` fails above 4,000 characters, and the comparison prints the lengths.
- The comparison prints over a hundred p-values; with ten runs a side a few below 0.05 arise by chance, so only the primary set (D-06) bears on the repair and a p-value is per cell and per grader, never pooled.
- The agent-path `r.`, `launch-only` and `reports` numerator are `read-traces.mjs`'s counts over every run without an `error`, a skipped-paid-graders run included, and the `reports` denominator is every run, on the baseline and the after side alike; every grader count covers clean runs only.
- The harness checks a ceiling only before it launches a run and compares spending after it, so the cap can be passed by at most one run's cost; no paid run starts after a `check` refuses.
- `model: inherit` raises the researcher's cost for every caller in a real install (brainstorm, frontend-design), not only in the eval; routing to the researcher when a prompt does not name it is not measured; this repository's installed `.claude/` copies keep the old text and model until a reinstall.
- The after-pilots and after-cells run on `claude` 2.1.286 while the baseline ran on 2.1.285 (user decision, 2026-10-01), so a difference may come partly from the host version.
- The first eight after-pilots were launched with `node` v20.20.2 on `PATH` (pilot 8's free checks ran on v22.23.3), the rest of task 03 and all of task 04 with v22.23.3 (user decision, 2026-10-01); `claude` runs as its own executable, so `node` serves the harness's version read and the reading scripts, and only a model that itself runs `node` in a case would see the change.
- Every lexical limit of `specs/research-eval-baseline/plan.md` (Known limits) applies unchanged: the instrument is the same bytes.
