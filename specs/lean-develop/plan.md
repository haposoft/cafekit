## Known limits
- Two cases only. Rules with no grader, guarded by pins and the words-unchanged check alone: `--flash`/`--parallel` rejection via `workflow-policy.cjs`; `--notes` opt-in; Resolve rules (explicit task path wins, read GATE-SCOPE scope and exclusions, dependency `done` with a valid Receipt, direct work only when clear, isolated, reversible, low-risk; ambiguity/overlap/cycle/missing plan is a blocker); the accepted fast path (no replanning, no routine user gate); load the plan index once; every row of the current-byte selection table (several `in_progress`, resume, `paused`, `blocked`, `done`, malformed Status); concurrent-invocation drift stop; specific-task mode never chains; Sequential mode one task at a time; Parallel and Flash modes; Scout (trace entrypoints, read the judging test first, reachability over compilation); interrupted-task recovery; Ownership/scope expansion back to GATE-SCOPE; subagent dispatch and controller-only writes; review owner and verdict vocabulary; three repair rounds then ask; no blind retry of a blocked environment; Receipt last after review; checkbox rule; feature-level integration, final-Head fixed point and GATE-DONE; docs impact; Definition of done (`PASS_WITH_WARNINGS`, `NO_TESTS`, `FLASH_UNVERIFIED` cannot close).
- Of the graded behaviour, hong checks the pre-change run and the BLOCKED stop; sach checks closing with a full Receipt and not stopping. A pass on a single-task fixture says nothing about queue chaining.
- `code-tieng-viet` and `code-cat-khoang-trang` are watch (D-06), and no graded signal sees code quality in sach: `JOINT.sach` is `dong-task && receipt-day-du && !dung-blocked` (`evals/develop/compare.mjs:24`) and `dong-task` only matches `Status: done`. A lean skill that edits code worse in sach is caught only by the hand reading of `--- greet` blocks in the GATE-DONE report.
- Ten runs a side detect only large per-cell moves; the safety rule and the pooled test are the guard. Pooled lines per model cover one cell per direction for most graders.
- The lean comparison counts runs that hit `max_turns` (30) or the 1200 s timeout; `evals/develop/compare.mjs` leaves them out. `save-runs` records `cap=` per run for GATE-DONE.
- `budget.mjs` counts only finished `result.json`; with two lanes running, the spend can overshoot the cap by up to one cell per lane ($8 max each).
- The line floor moves 140 → 115 (D-02, decided at GATE-REVIEW 2026-10-07); a test-threshold change shown again at GATE-DONE.
- After this packet nothing keeps develop at ≤125 lines: the self-test ceiling stays 200, so a later edit can grow the skill back without a failing test.
