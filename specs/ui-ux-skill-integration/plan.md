### Known upstream behaviours kept as-is (GATE-DONE must see these)
- `probe.mjs` is not read-only toward the page: it clicks up to 20 `[aria-haspopup]` elements and 10 "opener" buttons, and at mobile widths taps up to 10 truncated-text elements with `force: true` (`scripts/probe.mjs:1997-2515,3376-3384`). Point it at wireframes, mock data, or a dev server without a live backend.
- `probe.mjs` loads Playwright from `--pw`, then the current directory, then its own directory; a project with its own `node_modules/playwright` needs `--pw .claude/skills/ui-ux/scripts`. When `chromium.launch()` fails it silently uses the system Chrome channel.
- The skill instructs the model to `curl -sI` Unsplash links, embed `images.unsplash.com` / `randomuser.me` hotlinks as mock images, add those hosts to `next.config` `images.remotePatterns`, and run `python3 -m http.server <port>` in the background with no stop step (`SKILL.md:364-377`, `references/design-process.md:522`, `references/review.md:462-468`). CafeKit's installed rules still bind the model: `process-management.md` (track and stop what you start) and `ai-dev-rules.md` surgical scope (a `next.config` edit for mock images is a change the user did not ask for).
- `scripts/lint-skill.mjs` ships but is upstream's authoring linter (cwd-bound `skillDir`, `git diff HEAD`); CafeKit does not run it.
- No prompt-injection-shaped content was found (grep over SKILL.md, references, scripts for EN/VI "ignore previous / override / hide output / exfiltrate / system prompt / credential" patterns: 0 hits beyond UI copy).
