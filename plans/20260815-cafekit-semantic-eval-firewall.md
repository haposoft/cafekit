## 1. Executive summary

Stop false-ready and case patching via a **real change-firewall** with:

- fail-closed **tracked baseline authority** using a bootstrap/released discriminated union and **named reserved transitions** only, where empty-protected-path validity is **conditioned on authority state** (bootstrap: always invalid; released: always valid) instead of a blanket HEAD-equality rule, so a clean no-change freeze never deadlocks;
- **non-self-referential freeze** that binds authority digest + generation, with the reserved baseline-authority path excluded from generic derivation **before** the diff runs so its own bootstrap/advance writes never self-block, while an out-of-band edit still fails C10's own load/validate checks;
- **C1 proposal** as pure semantic fields; **C9 freeze** as sole digest binder (no circular digests);
- **repair_round as attempt index derived from a durable C13 `semantic_review_history` lineage** (append-only, digest-referenced, idempotent on replay) with separate reviewer verdict vs lifecycle disposition, a `review_epoch` that scopes the attempt budget to the current PASS-closed epoch instead of the whole lineage, and a single caller-input rule (reject, never silently ignore);
- **complete C11 IR** equality and mode authority, using a **parser-compatible tagged-union method shape** and **one exact ASCII ordinal comparator** (not `localeCompare`) for every sort;
- **exact C12 `ReleaseReceipt` contract** gating `advanceBaseline`, with an externally computed, non-circular digest and a `resolvedFailureIds` field that drives the new benchmark-failure ledger's `resolveFailure` transition;
- **new C15 `BenchmarkFailureLedger`**: a durable, append-only, generation+digest-chain-provenanced record of `opened`/`classified`/`reclassified`/`resolved` benchmark failures, reserved under D1 exactly like the baseline file, bound into C9 freeze digest+generation, gating `authorized_evolution` unconditionally on any open-entry intersection (only `benchmark_remediation` may cite `failure_ids`, and only when they exactly match) with no bypass on a missing-when-required or malformed ledger;
- **new C16 `AuthoringValidationReceipt`**: a durable per-stage digest binding (requirements/design raw bytes; research raw bytes or `RESEARCH_ABSENT_DIGEST`; tasks an ASCII-sorted stable-JSON bundle digest or `TASKS_ABSENT_DIGEST`) that makes an `authoring.*` `validated` reading provably fresh instead of trusted on the enum alone; a single atomic `spec-authoring-validation.cjs` coordinator (D13) is the sole writer of any stage's `validated` transition together with this receipt, all-or-nothing; every consumer (validator, finalizer, `authorized_evolution`) applies the identical freshness algorithm;
- **an exact, narrow, sequence-bound legacy-bridge boot-window** (D11/I9) — the legacy PASS exempts build-only work on exactly R0-01/R1-01/R1-02, never invoking `bootstrapBaseline` or publishing; a fresh, real, post-cutover review must PASS first, seeding the durable lineage at `sequence 0`/`review_epoch 0`, before bootstrap activates live gating for R2-01..R6-01, and the final release never covers only the boot-window;
- **sole normative protected allowlist in design D1** via **directory-prefix coverage** (`scripts/`, `bin/__tests__/`, `benchmarks/`) with **two** reserved control-plane exceptions (`release-baseline.json` under C10, `benchmark-failure-ledger.json` under C15) so every task write_set — including `candidate-isolation.mjs` and the non-`*.semantic-firewall.test.js` contract tests — is covered without a divergent list;
- **semantic-firewall test discovery** with per-task `--require-semantic-test`;
- frozen C2, dual-run IR, public 8, ownership write_sets, unconditional kernel ban, legacy bridge after PASS only.

### 3.4 Repair_round (grounded in durable history, epoch-scoped)

Indices 0..2 only, naming the epoch's first/second/third attempt. A PASS closes its epoch; the next entry opens `review_epoch + 1` at `attempt_index 0`. Reviewer verdict remains PASS|FAIL. A replayed receipt digest is not appended twice anywhere in the lineage (idempotent, whole-lineage dedupe unchanged). `lineage_id` is stable across ordinary semantic edits (I6); caller-supplied repair_round/review_epoch/history/lineage_id is **rejected** outright on divergence — single rule, no "ignore" path. `authorized_evolution`'s cited PASS entry must have its own `semantic_digest` equal to the current `spec_semantic_digest`, not merely some older PASS left over from a prior digest.
