## Layout sau khi cài

```
.claude/
├── skills/         # Workflow + domain skill packs (question, brainstorm, specs, ...)
├── agents/         # Subagent prompts (brainstormer, code-auditor, ...)
├── hooks/          # Event-driven CommonJS scripts
├── rules/          # Workflow, dev, docs, hook, state-sync rules
├── scripts/        # Helper scripts (catalog generator, ...)
├── references/     # Static lookup material
├── runtime.json    # Locale, paths, docs.maxLoc, gemini model
├── settings.json   # Hook bindings và permissions
└── status.cjs      # Statusline renderer
CLAUDE.md           # Operating instructions ở project root
.mcp.json           # Optional MCP server config
```

## Hooks

Claude Code có hooks event-driven trong `.claude/hooks/`:

| Hook | Event | Purpose |
|---|---|---|
| `privacy-block.cjs` | `PreToolUse` | Chặn read path nhạy cảm cho đến khi user approve |
| `inspect-block.cjs` | `PreToolUse` | Gate inspection scan diện rộng |
| `spec-state.cjs` | `PostToolUse` | Từ chối task `done` khi chưa có verification receipt |
| `session.cjs` | `SessionStart` | Inject session banner + context |
| `rules.cjs` | `UserPromptSubmit` | Inject dynamic per-prompt rules block |

Xem [Runtime bundle](/docs/runtime) để biết chi tiết hook contract.

## Commands

Claude Code dùng namespace `cf:`:

```
/cf:ask         /cf:brainstorm    /cf:specs       /cf:develop
/cf:test        /cf:code-review   /cf:sync        /cf:debug
/cf:fix      /cf:docs          /cf:scout       /cf:git
```

Cộng tất cả domain skill dưới dạng `/cf:<skill>`.

## Detection

Installer detect Claude Code khi có:

- Thư mục `.claude/`
- `CLAUDE.md` ở project root
- `.mcp.json` ở project root

Chạy lại installer là idempotent — file đã có sẽ được merge nơi nào an toàn, không ghi đè mù.
