## CafeKit là gì

CafeKit là runtime bundle đặt trong repo cho AI coding assistants. Package hiện tại là `@haposoft/cafekit`, cài bằng `npx @haposoft/cafekit`.

Nó tạo workflow có cấu trúc quanh Claude Code và Codex CLI:

## Bắt đầu bằng SDD

CafeKit xoay quanh **specification-driven development**: ý tưởng chỉ thành code sau khi thành contract có source backing. Bắt đầu bằng trang trực quan: [Spec-driven development](/vi/docs/spec-driven-development).

Sau đó đọc sâu theo đường: [Workflow chính](/vi/docs/core-workflow) → [Vòng đời spec](/vi/docs/spec-lifecycle) → [Skills](/vi/docs/skills).

## Cài những gì

CafeKit cài một runtime thật, không chỉ là vài đoạn hướng dẫn.

<RuntimeBundle />

Package hiện tại có **18 core skills** và **6 skill tài liệu/multimodal tuỳ chọn**, **13 agents**, installer support cho **Claude Code** và **Codex CLI**, cùng các validator deterministic cho spec và docs bundle.

## Cam kết cốt lõi

CafeKit không cố làm assistant nhanh hơn bằng cách bỏ quy trình. Nó làm assistant an toàn hơn bằng source-backed context, task boundary rõ, verify mới, adversarial review, và state sync.
