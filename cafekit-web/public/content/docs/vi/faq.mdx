## OpenCode hiện còn supported không?

Không. Release hiện tại support Claude Code và Codex CLI. OpenCode support kết thúc từ CafeKit 0.17; site chỉ giữ command map 0.16 cho migration lịch sử.

## Task nào cũng cần `/cf:specs`?

Không. Dùng specs cho feature work có ý nghĩa. Dùng `/cf:debug` và `/cf:fix` cho bugs. Fix nhỏ local có thể không cần full spec.

## Vì sao CafeKit cần task files?

Task files giữ scope, steps, completion criteria, và evidence. Chúng nối human intent với machine-checkable state.

## `NO_TESTS` có phải pass không?

Không. Nó chỉ nói rằng chưa có test suite thật nào chạy. Build health, runtime proof, và task evidence vẫn quan trọng.

## Có thể mark `done` từ chat không?

Không. `done` cần fresh verification và final inline Receipt hiện tại trong task. C3 vẫn là quyết định completion của user.

## Production bug thì dùng gì?

Bắt đầu bằng `/cf:debug` khi chưa biết root cause. Dùng `/cf:fix` sau diagnosis hoặc khi bug và target fix đã rõ.
