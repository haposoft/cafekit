## Current support

- [Claude Code](/docs/platforms/claude) — `.claude/` skills, agents, hooks, runtime và `CLAUDE.md`.
- **Codex CLI** — `.agents/skills`, `.codex/agents`, rules, scripts, hooks, runtime và managed `AGENTS.md` block.

Physical package dirs có thể giữ legacy internal names; public skill names vẫn là `ask`, `scout`, `fix`.

OpenCode support kết thúc từ CafeKit 0.17. [Ghi chú OpenCode 0.16](/docs/platforms/opencode) chỉ còn cho migration lịch sử. Cursor chưa phải current packaged target.
