## Bản đơn giản

Spec là contract bền vững, không phải chat memory. New work lưu contract trong `specs/<feature>/plan.md` và flat `task-NN-*.md`.

<SddLoopVisual locale="vi" />

## Mỗi artifact trả lời gì

<SddArtifactMap locale="vi" />

| Artifact | Câu hỏi |
|---|---|
| `plan.md` | Outcome, scope, exclusions, acceptance, decisions và task map nào đã được duyệt? |
| `task-NN-*.md` | Một outcome nào executable, ai sở hữu và exact proof nào bắt buộc? |
| Final inline `## Receipt` | Command và current output nào chứng minh task pass? |

## Working rule

1. Chỉ brainstorm khi intent hoặc architecture chưa giải quyết.
2. Specs mở C1, viết plan/tasks rồi trình C2 findings.
3. Planning dừng; chỉ bắt đầu bằng invocation develop mới.
4. Develop chạy một unblocked task; test và code review verify.
5. Sync chỉ Status/proof đã quan sát; user quyết định completion tại C3.

<SddCompareVisual locale="vi" />

Dùng full path cho work đáng kể, risk cao, multi-file, runtime, data, auth, package hoặc cần handoff. Clear isolated routine change một-hai file có thể làm trực tiếp.
