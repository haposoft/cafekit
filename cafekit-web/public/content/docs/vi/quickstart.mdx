<Callout type="info">Mới dùng CafeKit? Xem [tutorial từng bước](/docs/tutorial).</Callout>

## 1. Cài đặt

```bash
npx @haposoft/cafekit
```

## 2. Tạo và review spec

```text
/cf:specs Build a meeting transcript extension with AI summaries
```

Specs mở C1 rồi tạo:

```text
specs/<feature>/
├── plan.md
└── task-01-*.md
```

Tại C2, accept findings, yêu cầu sửa hoặc KEEP một named limitation. Planning dừng sau C2.

## 3. Explicit implementation

```text
/cf:develop <feature>
```

Develop chạy từng unblocked task, chạy exact planned proof và để controller ghi final inline Receipt.

## 4. Verify và review

```text
/cf:test --full
/cf:code-review --pending
```

`NO_TESTS` và zero executed tests không phải pass.

## 5. Sync và đóng

```text
/cf:sync <feature>
```

Sync chỉ state và proof đã quan sát. Tại C3, user quyết định receipts hiện tại và unresolved limitations đã đủ để đóng chưa.
