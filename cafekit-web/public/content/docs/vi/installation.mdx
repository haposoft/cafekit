## Yêu cầu

- Node.js `>=18`
- Project root có quyền ghi
- Claude Code hoặc Codex CLI, hoặc chọn runtime rõ ràng khi cài

## Cài và nâng cấp

```bash
npx @haposoft/cafekit
npx @haposoft/cafekit --upgrade
```

Bản cài mới có 18 core skills. Installer tương tác cho phép chọn thêm `docs`,
`docx`, `pdf`, `pptx`, `xlsx`, và `ai-multimodal`; non-interactive mặc định bỏ qua:

```bash
npx @haposoft/cafekit --with-document-skills
npx @haposoft/cafekit --without-document-skills
```

Lệnh thứ hai gỡ bản skill còn nguyên do CafeKit sở hữu; file người dùng đã sửa
được giữ lại. Bản cài legacy giữ bundle khi upgrade lần đầu.

## Runtime được cài

| Runtime | Detection | Installed shape |
|---|---|---|
| Claude Code | `.claude/` | skills, agents, hooks, settings, runtime, `CLAUDE.md` |
| Codex CLI | `.codex/`, `.agents/`, hoặc `--platform codex` | `.agents/skills`, `.codex/agents`, rules, scripts, hooks, runtime và managed `AGENTS.md` block |

Nếu không có marker, installer hỏi runtime cần cài.

## Verify

Claude Code: `/cf:specs Build a tiny verified feature`

Codex CLI: `$cf-specs Build a tiny verified feature`

Version và lựa chọn bundle tài liệu được ghi tại `.claude/cafekit.json` hoặc `.codex/cafekit.json`.
