## What CafeKit is

CafeKit is a repo-local runtime bundle for AI coding assistants. The current package is `@haposoft/cafekit`, installed with `npx @haposoft/cafekit`.

It adds a structured workflow around Claude Code and Codex CLI:

## Start with SDD

CafeKit is built around **specification-driven development**: an idea becomes code only after it becomes a source-backed contract. Start with the visual guide: [Spec-driven development](/docs/spec-driven-development).

After that, the deeper path is [Core workflow](/docs/core-workflow) → [Spec lifecycle](/docs/spec-lifecycle) → [Skills](/docs/skills).

## What it installs

CafeKit installs a working runtime, not just documentation snippets.

<RuntimeBundle />

The package currently ships **18 core skills** plus **6 optional document and multimodal skills**, **13 agents**, installer support for **Claude Code** and **Codex CLI**, and deterministic validators for specs and documentation bundles.

## Core promise

CafeKit does not try to make the assistant faster by removing process. It makes the assistant safer by forcing source-backed context, explicit task boundaries, fresh verification, adversarial review, and synchronized state.
