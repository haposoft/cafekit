<Callout type="info">New to CafeKit? Use the [step-by-step tutorial](/docs/tutorial) for the guided version.</Callout>

## 1. Install

```bash
npx @haposoft/cafekit
```

## 2. Create and review the spec

```text
/cf:specs Build a meeting transcript extension with AI summaries
```

Specs opens C1, then creates:

```text
specs/<feature>/
├── plan.md
└── task-01-*.md
```

At C2, accept findings, request revisions, or KEEP a named limitation. Planning stops after C2.

## 3. Implement explicitly

```text
/cf:develop <feature>
```

Develop executes one unblocked task at a time. It runs the exact planned proof and writes the task's final inline Receipt through the controller.

## 4. Verify and review

```text
/cf:test --full
/cf:code-review --pending
```

`NO_TESTS` and zero executed tests are not a pass.

## 5. Sync and close

```text
/cf:sync <feature>
```

Sync only observed Status and proof. At C3, the user decides whether current receipts and unresolved limitations are sufficient to close.
