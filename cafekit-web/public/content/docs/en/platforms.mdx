## Pick your platform

- [Claude Code](/docs/platforms/claude) — `.claude/` skills, agents, hooks, runtime, and `CLAUDE.md`.
- **Codex CLI** — `.agents/skills`, `.codex/agents`, rules, scripts, hooks, runtime metadata, and a managed `AGENTS.md` block.

Each runtime consumes the shared CafeKit contract through its native project surfaces. Physical package directories may keep legacy internal names while public skill names remain `ask`, `scout`, and `fix`.

## Detection

| Platform | Markers |
|---|---|
| Claude Code | `.claude/`, `CLAUDE.md`, `.mcp.json` |
| Codex CLI | `.codex/`, `.agents/`, or explicit installer selection |

If multiple current targets are detected, the installer offers a per-target choice.

## Future platforms

OpenCode support ended in CafeKit 0.17; [OpenCode 0.16 notes](/docs/platforms/opencode) remain only for historical migration. Cursor is not a current packaged runtime target.
