## OpenCode は current support ですか？

いいえ。Current releases は Claude Code と Codex CLI を support します。OpenCode support は CafeKit 0.17 で終了し、0.16 command map は historical migration 用だけに残ります。

## すべての task に `/cf:specs` が必要ですか？

いいえ。meaningful feature work には specs を使います。bugs には `/cf:debug` と `/cf:fix` を使います。小さな local fix は full spec を必要としない場合があります。

## なぜ task files が重要ですか？

task files は scope、steps、completion criteria、evidence を保存します。human intent と machine-checkable state をつなぐ layer です。

## `NO_TESTS` は pass ですか？

いいえ。real test suite が実行されていないという意味だけです。build health、runtime proof、task evidence はまだ必要です。

## chat だけで `done` にできますか？

できません。Done には fresh verification と task 内の current final inline Receipt が必要です。C3 は user の completion decision です。

## production bug は何を使いますか？

root cause が不明なら `/cf:debug` から始めます。diagnosis 後、または bug と target fix が明確なら `/cf:fix` を使います。
