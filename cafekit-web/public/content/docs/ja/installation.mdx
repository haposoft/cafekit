## Requirements

- Node.js `>=18`
- 書き込み可能な project root
- Claude Code、Codex CLI、または明示的 runtime selection

## Install and upgrade

```bash
npx @haposoft/cafekit
npx @haposoft/cafekit --upgrade
```

Fresh install には 18 core skills が含まれます。Interactive installer では
`docs`, `docx`, `pdf`, `pptx`, `xlsx`, `ai-multimodal` の optional bundle を
選択できます。Non-interactive install は明示しない限り bundle を含みません。

```bash
npx @haposoft/cafekit --with-document-skills
npx @haposoft/cafekit --without-document-skills
```

後者は CafeKit-owned で未変更の skill を削除します。ユーザー変更は保持され、
legacy install は最初の upgrade で bundle を維持します。

## Installed runtimes

| Runtime | Detection | Installed shape |
|---|---|---|
| Claude Code | `.claude/` | skills、agents、hooks、settings、runtime、`CLAUDE.md` |
| Codex CLI | `.codex/`、`.agents/`、または `--platform codex` | `.agents/skills`、`.codex/agents`、rules、scripts、hooks、runtime、managed `AGENTS.md` block |

Marker がない場合、installer が runtime を質問します。

## Verify

Claude Code: `/cf:specs Build a tiny verified feature`

Codex CLI: `$cf-specs Build a tiny verified feature`

Version と document bundle の選択は `.claude/cafekit.json` または `.codex/cafekit.json` に記録されます。
