## Current support

- [Claude Code](/docs/platforms/claude) — `.claude/` skills、agents、hooks、runtime、`CLAUDE.md`。
- **Codex CLI** — `.agents/skills`、`.codex/agents`、rules、scripts、hooks、runtime、managed `AGENTS.md` block。

Physical package dirs は legacy internal names を保持できますが public skill names は `ask`、`scout`、`fix` です。

OpenCode support は CafeKit 0.17 で終了しました。[OpenCode 0.16 notes](/docs/platforms/opencode) は migration history 用です。Cursor は current packaged target ではありません。
