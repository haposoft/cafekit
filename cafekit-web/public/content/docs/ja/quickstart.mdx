<Callout type="info">CafeKit が初めてなら [step-by-step tutorial](/docs/tutorial) を利用してください。</Callout>

## 1. Install

```bash
npx @haposoft/cafekit
```

## 2. Spec creation and review

```text
/cf:specs Build a meeting transcript extension with AI summaries
```

Specs は C1 を開き、次を作成します:

```text
specs/<feature>/
├── plan.md
└── task-01-*.md
```

C2 で findings を accept、revision request、または named limitation として KEEP。Planning は C2 後に停止します。

## 3. Explicit implementation

```text
/cf:develop <feature>
```

Develop は one unblocked task ずつ実行し、exact planned proof を run、controller が final inline Receipt を書きます。

## 4. Verify and review

```text
/cf:test --full
/cf:code-review --pending
```

`NO_TESTS` と zero executed tests は pass ではありません。

## 5. Sync and close

```text
/cf:sync <feature>
```

Sync は observed state と proof だけを更新します。C3 で user が current receipts と unresolved limitations が close に十分か決定します。
