## Routing rule

task に合う最小の skill を選びます。小さな fix に full spec workflow を強制せず、request が曖昧なまま code を始めません。
Explicit または明確な low-risk work は native selection で直接処理し、
material な ambiguity、chain、domain、risk の場合だけ短い chain を構成します。
ドキュメント capability はオプションで、インストール時のみ利用できます。
セマンティック selection は非決定的で、live-model adherence の proof ではありません。
